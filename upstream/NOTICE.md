# upstream/

An unmodified snapshot of the original ZazenCodes software factory, taken from
<https://github.com/zazencodes/zazencodes-season-3/tree/main/src/software-factory-claude-code>
at commit `555467c365e6750278efba09349369109f62f65f` (2026-10-07).

It is kept for two reasons: as the reference the new factory was assessed against (docs/ASSESSMENT.md), and as
fixtures — its two example jobs in `factory/jobs/` are read by the engine and the console as read-only v1 jobs.

The source repository carried no license file when the snapshot was taken, so this directory is **not** covered by
this repository's MIT license. Before publishing this repository, confirm the terms with the original author or
remove this directory (the tests that read its example jobs then need fixtures of their own).
